# KT website showcase video (Remotion)

A 2-minute, 1080p demo video of the new kavaiyatech.com, made with [Remotion](https://www.remotion.dev/).
Every website image in it is a real screenshot of the built site in `../03-new-site/dist` (and of the current site, for the "before" scene).
The music is an original track generated by `scripts/music.mjs`; no licensed audio is used.

Output: `out/kt-showcase.mp4` (not committed; regenerate with the steps below).

## Scenes (plain-English script)

| Time | Scene | What the viewer sees and reads |
|---|---|---|
| 0:00–0:08 | Intro | The KT logo assembles from its four ribbons in 3D, the KAVAIYATECH wordmark writes in. "Introducing the new kavaiyatech.com." |
| 0:08–0:20 | Where things stand | The current site as one endless tilted page (about 28 laptop screens). Three findings: 2 pages for search engines, no enquiry form, 69/100 on phones. |
| 0:20–0:34 | The new website | The new home page swings in. Callouts: clear headline, animated logo, one next step. Then a full scroll. |
| 0:34–0:48 | Services | Pointer hovers the services list; all 8 service pages orbit in 3D; counter 2 → 16 pages. |
| 0:48–1:00 | Design | Camera glides over the page like a technical drawing: zone markers, the company title block, the ten-sector table. |
| 1:00–1:12 | Light and dark | Click on the theme switch; dark mode ripples out; both themes scroll side by side. |
| 1:12–1:26 | On phones | Two 3D phones: one scrolling, one opening the full-screen menu. |
| 1:26–1:38 | Getting in touch | The real contact form is filled in (demo details) and sent; confirmation appears. |
| 1:38–1:50 | Under the hood | Lighthouse scores fill up (speed on phones 69 → 98, others 100) and three plain guarantees. |
| 1:50–2:00 | Outro | Logo, "Ready to launch", prepared by Vyas Devgna. |

Numbers shown come from the audit and the local Lighthouse runs in `../03-new-site/BUILD-NOTES.md`.

## Rebuild

```bash
npm install
# 1. serve the new site and a local copy of the current site
node ../03-new-site/scripts/serve.mjs 8080 &
# (current-site copy on :8099 is only needed for the "before" shot)
# 2. capture screenshots and positions, generate the music
PLAYWRIGHT_PATH=<path to playwright> node scripts/capture.mjs
PLAYWRIGHT_PATH=<path to playwright> node scripts/measure.mjs
node scripts/music.mjs
# 3. preview or render
npx remotion studio
npx remotion render KTShowcase out/kt-showcase.mp4
```

On machines without Remotion's own browser download, add `--browser-executable=<path to chrome-headless-shell>`.
