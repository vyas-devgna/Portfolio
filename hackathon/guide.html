Participant checklist

Just follow these steps.

Start at the top. Tick each box after finishing that step. Your progress stays on your own device.

01

Before the coding round

Get the team and GitHub ready.

01

Open your hackathon page

Open the hackathon page and tap Log in with GitHub. Use the same GitHub account that was given during registration.

02

Check your team details

Open My Account → Hackathons → My Hackathons. Find your team. If you see Confirm Your Participation, fill in the required details and tap Save Address. If somebody is missing, ask the team leader to add them.

03

Find your mentor and join Discord

On the left side of the hackathon page, look for Mentor. Note the GitHub username shown there. Then tap the green Join Group button to join Discord before the coding round.

04

Create one GitHub repository

One person per team

One person should open github.com/new, enter a project name, and tap Create repository. Share that repository link with the team. You only need one repository for the solution.

05

Add the mentor and teammates

Repository owner

On GitHub, open the new repository, then go to Settings → Collaborators → Add people. Search for your mentor’s GitHub username and send an invitation. Add teammates who need to push code, too. Check that the invitations are accepted.

06

Check the timings

Look at the Milestones section of your hackathon page. Check when problems are released, when coding ends, and when repository and video links are due. Use the dates on your own event page.

02

During the coding round

Choose the problem, build, and submit code.

07

Download the problem statements

When the coding round starts, find Problem Statements on the hackathon page. Tap Download to read each problem fully. Discuss the options with your teammates.

08

Select your problem

Team leader only

After the team agrees, the team leader chooses a problem in the Problem Statements dropdown. Once confirmed, the choice cannot be changed.

09

Build, test, and push your code

Develop the solution, test that it works, and push code to GitHub regularly. Keep the final code in one branch. Put simple run instructions in your README. Do not leave the only copy on a laptop.

10

Submit the repository link

Team leader only

When Submit Github Repo Link appears, the team leader pastes the full GitHub repository URL and submits it. Check the URL carefully and make sure the latest working code is pushed before the deadline.

03

Final submission

Record and submit the demo.

11

Record a demo video

Record your screen while the application is running. Briefly show the problem, your solution, and the main features actually working. Aim for 10 minutes or less based on the instructions shared; check your event page for its exact limit.

12

Upload the video to Google Drive

Open Google Drive and upload the video. Open Share → General access → Anyone with the link, set permission to Viewer, and copy the link. Test it in a private browser tab.

13

Submit the video link

Team leader only

Back on the hackathon page, tap Submit Video Solution. Paste the Google Drive video link and submit it. Check for the confirmation message. Use Update Submission if you need to fix the link.

After submission

When results are announced, check Team Rank on the same hackathon page.

If something on the portal is not working, open Hackathon Assistance in the Helpdesk section.

Based on the Odoo Hackathon Participant Document. Screenshots are examples; your event may look different. Completing this checklist does not submit anything on the official portal.
